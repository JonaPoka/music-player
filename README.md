# Vinyl Player Inspired Music Player Widget for Notion

A cozy vinyl player widget I created for my Notion. Plays music files specified in songs.json with clean animations.

Test it out on web https://jonapoka.github.io/music-player/

or add it to your website:

```html
<iframe 
	src="https://jonapoka.github.io/music-player/"
	width="100%" 
	height="600"
	frameborder="0"
	allow="autoplay"
	style="border-radius:12px; overflow:hidden;">
</iframe>
```
